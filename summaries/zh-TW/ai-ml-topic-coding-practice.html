LC 72 · 09 / 28

Edit Distance

Medium起步題
NeetCode 解題 ↗LeetCode 72 ↗

工作主題NLP / LLM · Evaluation / Causal · Multimodal / CV / Speech

解題技術Dynamic Programming

可延伸到 ASR 的 WER、OCR 的 CER；這題先處理字元級編輯次數。

題目、Python 解法與面試講解

題目整理

用插入、刪除、替換，把 word1 變成 word2，回傳最少操作數。

word1="cat", word2="cut" → 1

解法說明

每個 prefix pair 的最佳答案只依賴插入、刪除、替換的較短 prefix；相同字元不需付費。

class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        previous = list(range(len(word2) + 1))
        for i, ch1 in enumerate(word1, 1):
            current = [i]
            for j, ch2 in enumerate(word2, 1):
                if ch1 == ch2:
                    current.append(previous[j - 1])
                else:
                    current.append(1 + min(
                        previous[j],      # Delete from word1.
                        current[j - 1],   # Insert into word1.
                        previous[j - 1],  # Replace.
                    ))
            previous = current
        return previous[-1]
Time
O(mn)
Space
O(n)

m、n 為兩字串長度；只保留上一列與目前列。

Interview Explanation Flow

  1. I would confirm that each insertion, deletion, or substitution costs one, and that we need the count rather than the edit sequence.
  2. I define dp[i][j] as the distance between two prefixes. Matching characters keep the diagonal cost; otherwise I add one to the cheapest neighboring state.
  3. As I code, the first row and first column handle empty prefixes. Each row only needs its predecessor, so I keep two rows.
  4. Time is O(mn), space is O(n). I would test two empty strings, one empty string, and identical strings. To return the edits, I would retain predecessor information.
"cat" → "cut": replace a with u → 1
"" → "abc": insert a, b, c → 3

中文：先定義兩個 prefix 的距離，再解釋三種操作各自對應哪個相鄰狀態。

LC 743 · 12 / 28

Network Delay Time

Medium
NeetCode 解題 ↗LeetCode 743 ↗

工作主題Agents / Planning · Production / Efficiency

解題技術Graph · Heap

練習帶成本的 graph search；本題求所有節點收到訊號的最晚時間。

題目、Python 解法與面試講解

題目整理

有非負邊權的有向圖，從 k 發送訊號，回傳所有節點收到的最短所需時間；有人不可達則 -1。

times=[[1,2,2],[2,3,1],[1,3,5]], n=3, k=1 → 3

解法說明

Dijkstra 每次確認最小暫定距離；答案是所有最短距離的最大值。

from heapq import heappop, heappush


class Solution:
    def networkDelayTime(self, times: list[list[int]], n: int, k: int) -> int:
        graph = [[] for _ in range(n + 1)]
        for source, target, weight in times:
            graph[source].append((target, weight))

        distance = [float("inf")] * (n + 1)
        distance[k] = 0
        heap = [(0, k)]
        while heap:
            cost, node = heappop(heap)
            if cost != distance[node]:
                continue  # Ignore a superseded candidate.
            for neighbor, weight in graph[node]:
                candidate = cost + weight
                if candidate < distance[neighbor]:
                    distance[neighbor] = candidate
                    heappush(heap, (candidate, neighbor))

        answer = max(distance[1:])
        return -1 if answer == float("inf") else answer
Time
O((V + E) log(V + E + 1))
Space
O(V + E)

以允許 heap 保留過期候選的實作為準。

Interview Explanation Flow

  1. I would confirm directed edges and nonnegative weights. We need the largest shortest-path distance from the source, not the sum of edge costs.
  2. I use Dijkstra: the heap exposes the smallest tentative distance, and relaxing an edge can improve a neighbor's distance.
  3. As I code, I discard outdated heap entries and push a new candidate only on strict improvement. This also avoids looping on zero-cost cycles.
  4. With lazy heap entries, the bound is O((V+E) log(V+E+1)) time and O(V+E) space. I would test a disconnected node, a zero-weight edge, and n=1.
1 → 2 costs 2; 2 → 3 costs 1; 1 → 3 costs 5
After node 1: distances = [0,2,5]
After node 2: distances = [0,2,3]
Return max = 3; the heap's old (5,3) entry is ignored.

中文：區分每個節點的最短到達時間與所有節點都收到訊號的時間。

class Solution:
    def combinationSum(self, candidates: list[int], target: int) -> list[list[int]]:
        candidates.sort()
        result = []
        path = []

        def search(start: int, remaining: int) -> None:
            if remaining == 0:
                result.append(path.copy())
                return
            for index in range(start, len(candidates)):
                value = candidates[index]
                if value > remaining:
                    break
                path.append(value)
                search(index, remaining - value)
                path.pop()  # Undo this choice before exploring another.

        search(0, target)
        return result
Time
O(c log c + c^(D+1) · D) 保守上界
Space
O(D + R·D)

c 為候選數，D=⌊target/min(candidates)⌋，R 為結果數；包含輸出，排除輸出為 O(D)。

Interview Explanation Flow

  1. I would confirm positive, distinct candidates, unlimited reuse, and that order within a combination does not matter.
  2. I search only in nondecreasing candidate order. Reusing the same index allows repetition, while never moving backward prevents permutation duplicates.
  3. As I code, I append a choice, explore, and pop it. I copy the path when the remaining target reaches zero; sorted values let me stop early.
  4. The search is exponential and output-sensitive. With c candidates and depth D, O(c^(D+1) D) is a conservative bound, plus sorting. Extra search space is O(D), and R results take up to O(RD) space.
[2,3], target=6
choose 2 → 2 → 2: remaining 0 → save [2,2,2]
undo choices; choose 3 → 3 → save [3,3]
No [3,2,...] branch: indices never move backward.

from random import choice


class RandomizedSet:
    def __init__(self):
        self.values = []
        self.positions = {}

    def insert(self, val: int) -> bool:
        if val in self.positions:
            return False
        self.positions[val] = len(self.values)
        self.values.append(val)
        return True

    def remove(self, val: int) -> bool:
        if val not in self.positions:
            return False
        index = self.positions[val]
        last = self.values[-1]
        self.values[index] = last
        self.positions[last] = index
        self.values.pop()
        del self.positions[val]
        return True

    def getRandom(self) -> int:
        return choice(self.values)

from collections import deque


class Solution:
    def maxSlidingWindow(self, nums: list[int], k: int) -> list[int]:
        candidates = deque()
        answer = []
        for right, value in enumerate(nums):
            while candidates and candidates[0] <= right - k:
                candidates.popleft()
            while candidates and nums[candidates[-1]] <= value:
                candidates.pop()
            candidates.append(right)
            if right >= k - 1:
                answer.append(nums[candidates[0]])
        return answer

O(n)
Space

Interview Explanation Flow

  1. I would confirm that k is between one and the array length. Repeatedly scanning each window would cost O(nk).
  2. An older element no larger than a newer one can never become the maximum again: the newer element is larger and expires later.
  3. As I code, the deque stores indices. I remove expired entries at the front, dominated entries at the back, and read the answer from the front once a full window exists.
  4. Each index is appended once and removed at most once, giving O(n) time and O(k) extra space. I would test k=1, k=n, decreasing values, and equal values.

from collections import deque


class Solution:
    def numIslands(self, grid: list[list[str]]) -> int:
        if not grid or not grid[0]:
            return 0
        rows, cols = len(grid), len(grid[0])
        seen = set()
        count = 0
        for r in range(rows):
            for c in range(cols):
                if grid[r][c] != "1" or (r, c) in seen:
                    continue
                count += 1
                seen.add((r, c))
                queue = deque([(r, c)])
                while queue:
                    x, y = queue.popleft()
                    for dx, dy in ((1, 0), (-1, 0), (0, 1), (0, -1)):
                        nx, ny = x + dx, y + dy
                        if (0 <= nx < rows and 0 <= ny < cols
                                and grid[nx][ny] == "1"
                                and (nx, ny) not in seen):
                            seen.add((nx, ny))
                            queue.append((nx, ny))
        return count

  2. Every previously unseen land cell starts a new connected component. BFS marks all cells belonging to that island.
  3. I mark cells when enqueuing them, so two neighbors cannot enqueue the same cell twice. A separate seen set preserves the input.

題目、Python 解法與面試講解

題目整理

判斷只含 ()[]{} 的字串，括號類型與巢狀配對順序是否正確。

"([])" → true；"([)]" → false

解法說明

Stack 記錄尚未關閉的左括號；每個右括號必須匹配最後開啟的括號。

class Solution:
    def isValid(self, s: str) -> bool:
        matching = {")": "(", "]": "[", "}": "{"}
        stack = []
        for char in s:
            if char in matching:
                if not stack or stack.pop() != matching[char]:
                    return False
            else:
                stack.append(char)
        return not stack
Time
O(n)
Space
O(n)

n 為字串長度。

Interview Explanation Flow

  1. I would confirm the input contains only the six bracket characters. Equal opening and closing counts alone do not prove validity.
  2. A stack represents the openings still waiting to close. Each closing bracket must match the most recently opened one.
  3. I check for an empty stack before popping, and require the stack to be empty at the end.
  4. The scan takes O(n) time and O(n) space. I would test a leading closing bracket, unmatched openings, and cross-nested brackets.
"([])": push (, push [, match ], match ) → true
"([)]": ) does not match the top [ → false

中文：配對需要最後開、最先關，因此使用 stack，而不是只計數。
